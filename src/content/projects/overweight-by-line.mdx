# Overweight by Line

## Overview
This dashboard tracks "giveaway" weight—product delivered in excess of the declared label weight. Reducing this variance directly impacts the bottom line.

### Key Features
- **Statistical Control**: visualizes distribution of package weights.
- **Outlier Detection**: Flags production runs with significant deviations.
- **Cost Calculation**: Estimates the financial loss due to material giveaway.

## Impact
By providing visibility into overweight trends, the production team optimized filling machine settings, reducing material giveaway by 2%.
