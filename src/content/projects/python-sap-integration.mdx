# Python Integration with SAP ERP for BI

## Overview
Automating the tedious process of extracting reports from SAP GUI. This script uses SAP scripting to export data, which then feeds into Power BI.

### Key Features
- **SAP GUI Scripting**: Automates button clicks and transaction codes (e.g., COOISPI).
- **File Management**: Automatically saves and renames export files.
- **Power BI Refresh**: Triggers dataset refreshes upon successful extraction.

## Impact
Eliminated 2 hours of manual daily reporting work, allowing the team to focus on analysis rather than data entry.
