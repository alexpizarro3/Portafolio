# Shoplogix API Query with Python

## Overview
A robust data pipeline interacting with the Shoplogix MES API to extract high-resolution production data.

### Key Features
- **Dynamic Date Handling**: Automatically queries data for custom or rolling date ranges.
- **JSON Parsing**: Flattens nested JSON responses into tabular structures suitable for SQL.
- **Error Handling**: Retries failed requests to ensure data completeness.

## Impact
Enabled granular analysis of machine performance down to the second, which was not possible with standard reporting tools.
