# Logistics KPIs Dashboard

## Overview
This project focuses on visualizing critical logistics performance indicators to drive data-driven decision-making.

### Key Features
- **Logistics Cost Analysis**: Detailed breakdown of costs by region and carrier.
- **Fill Rate Tracking**: Monitoring order fulfillment rates to improve customer satisfaction.
- **Inventory Health**: Tracking Days of Inventory (DOI) and risk of obsolescence.

## Technical Implementation
The solution involves a robust pipeline:
1. **Extraction**: Automated extraction from **SAP** using Python scripts.
2. **Transformation**: Data cleaning and shaping using Pandas and SQL.
3. **Loading**: Centralized data storage in SQL Server.
4. **Visualization**: Interactive Power BI dashboard with RLS (Row Level Security).

> "This dashboard reduced reporting time by 40% and identified cost-saving opportunities worth $50k annually."
