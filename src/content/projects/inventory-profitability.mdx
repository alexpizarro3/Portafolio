# Inventory & Profitability Analysis

## Overview
A comprehensive analysis using Python to perform ABC classification of inventory and analyze SKU profitability.

### Key Features
- **ABC Analysis**: Classifies items based on revenue impact (A: Top 80%, B: Next 15%, C: Bottom 5%).
- **Margin Analysis**:  Scatter plots visualizing Volume vs. Margin to identify "Cash Cows" and "Dogs".
- **Stock Turnover**: Analyzes inventory velocity.

## Tools Used
- **Pandas**: For heavy data manipulation and aggregation.
- **Plotly**: For interactive scatter and bar charts.
- **Google Colab**: For shareable, reproducible analysis.
