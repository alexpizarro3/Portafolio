# ETL with Python + SQL Server + Google Sheets

## Overview
This automated script bridges the gap between enterprise SQL databases and collaborative tools like Google Sheets.

### Key Features
- **Database Connection**: Securely connects to MSSQL Server using `pyodbc`.
- **Data Transformation**: Cleans and aggregates data using Pandas.
- **Cloud Upload**: Uses the Google Sheets API to push fresh data automatically.

## Use Case
Enables non-technical stakeholders to access live sales and inventory data in a familiar spreadsheet format without needing direct database access.
