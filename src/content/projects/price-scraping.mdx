# Price Web Scraping with Python

## Overview
A competitive intelligence tool that monitors competitor pricing across e-commerce platforms.

### Key Features
- **Dynamic Scraping**: Uses Selenium to handle JavaScript-rendered content.
- **Data Parsing**: BeautifulSoup extracts product names, prices, and availability.
- **Visualization**: Plotly charts show price trends over time.

## Use Case
Used by the sales team to adjust pricing strategies dynamically based on market position.
