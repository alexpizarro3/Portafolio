# Scrap Dashboard

## Overview
A comprehensive tool to monitor and analyze production waste (scrap), helping the manufacturing team identify specific lines, shifts, or products contributing to high material loss.

### Key Features
- **Real-time Monitoring**: Tracks scrap rates against targets.
- **Shift Analysis**: Compares performance across different shifts.
- **Material Breakdown**: Identifies which raw materials are wasted most frequently.

## Technical Details
Data is aggregated from shop floor logs and visualized in Power BI, enabling daily stand-up meetings to focus on immediate corrective actions.
