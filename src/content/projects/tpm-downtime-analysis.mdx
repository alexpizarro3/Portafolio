# TPM Downtime Analysis

## Overview
This project provides a deep dive into manufacturing downtime, categorizing losses into operational, mechanical, and electrical buckets to identify root causes.

### Key Features
- **Categorization**: Validates downtimes against standard OEE categories.
- **Granularity**: Drill-down capabilities from Plant -> Line -> Machine.
- **Trend Analysis**: Visualizes downtime trends over time to spot recurring issues.

## Impact
The insights from this dashboard led to a targeted maintenance strategy, reducing unplanned downtime by 15% and saving approximately **$50,000 USD** annually.
